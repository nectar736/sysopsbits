What the AZ-900 exam covers

AZ-900 (Microsoft Azure Fundamentals) checks foundational cloud and Azure knowledge. It's a common first certification for people moving into cloud roles. These are Microsoft's official domain weights from the skills outline effective July 20, 2026:

DomainWeightTypical topics
Describe cloud concepts25–30%Shared responsibility, public/private/hybrid, consumption-based pricing, IaaS vs PaaS vs SaaS, serverless
Describe Azure architecture and services35–40%Regions and availability zones, resource hierarchy, VMs, scale sets, AVD, VNets, VPN Gateway vs ExpressRoute, storage tiers and redundancy, Entra ID, Zero Trust
Describe Azure management and governance30–35%Cost management, pricing calculator, tags, Azure Policy, resource locks, Purview, Arc, ARM, Azure Monitor, Advisor, Service Health

Source: Microsoft's AZ-900 study guide.

How to use this practice test

  1. Take it once without notes to find your weakest domain.
  2. Read the explanation for every question. AZ-900 questions often hinge on one word ("most cost-effective", "least administrative effort").
  3. Fill the gaps with focused reading: Azure Virtual Machines for AZ-900 and Azure networking fundamentals cover the two areas that trip up most candidates.
  4. Retake it after a few days. If you score well above 70% both times, you're likely ready to book.

AZ-900 exam FAQ

What score do I need to pass AZ-900?

700 on a scale of 1–1000.

Does AZ-900 expire?

No. Microsoft fundamentals certifications don't expire and don't need renewal.

Is AZ-900 worth it if I already work in IT?

It's a quick win that gives you Microsoft's cloud vocabulary, and the vocabulary is what AZ-104 and AZ-140 assume you already know. If you already manage Azure day to day, you can skip straight to the AZ-104 practice test.

Are these real exam questions?

No. They're original questions written from the published skills outline.
