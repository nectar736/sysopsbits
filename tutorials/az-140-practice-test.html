What the AZ-140 exam covers

AZ-140 tests whether you can design, deploy, and run Azure Virtual Desktop. Microsoft weights the four domains like this in the skills outline effective July 20, 2026:

DomainWeightTypical topics
Plan and implement an Azure Virtual Desktop infrastructure40–45%Network capacity, RDP Shortpath and Multipath, Private Link, FSLogix storage, Azure Files and Azure NetApp Files, host pool design, licensing, images and Azure Compute Gallery
Plan and implement identity and security15–20%AD DS vs Microsoft Entra ID vs Entra Domain Services, Azure RBAC, Conditional Access, SSO, Defender for Endpoint, NSGs and Azure Firewall, Trusted Launch
Plan and implement user environments and apps20–25%FSLogix Profile Containers, ODFC and Cloud Cache, client settings, RDP properties, Start VM on Connect, application groups, RemoteApp, Teams, App attach
Monitor and maintain an Azure Virtual Desktop infrastructure10–15%Azure Monitor and AVD Insights, autoscale, session management, update strategy, backup, disaster recovery

This test follows those weights: 4 infrastructure questions, 2 on identity and security, 3 on user environments and apps, and 1 on monitoring. Source: Microsoft's AZ-140 study guide.

How to use this practice test

  1. Take it once without notes. Your first score shows which domain to study first.
  2. Read the explanation for every answer, including the ones you got right. AZ-140 questions turn on details like which role goes to the service principal and which goes to the user.
  3. Follow the Microsoft Learn source on anything you missed, then rebuild it in a lab.
  4. Fill the gaps with the AZ-140 guides on this site: core AVD resources and services, deploying your first host pool, FSLogix profile containers, Entra Kerberos for FSLogix on Azure Files, and RDP Shortpath and Private Link networking.

AZ-140 exam FAQ

What score do I need to pass AZ-140?

700 on a scale of 1 to 1000. Microsoft weights questions differently, so the scale isn't a percentage.

Does the AZ-140 certification expire?

Yes. Azure Virtual Desktop Specialty is valid for one year. You renew it for free by passing an online assessment on Microsoft Learn.

Should I pass AZ-104 before AZ-140?

Microsoft doesn't require it. AZ-140 assumes you already know Azure networking, storage, identity, and compute, so the AZ-104 practice test is a quick way to check those basics first.

How do the select-2 questions work on the real exam?

Microsoft exams include questions with more than one correct answer and tell you how many to pick. This test scores them all-or-nothing: you get the point only when both picks are right.

Are these real exam questions?

No. They're original questions written from the published skills outline and checked against Microsoft Learn. Microsoft's exam agreement prohibits sharing real exam content.
